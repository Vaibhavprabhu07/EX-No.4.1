# EX No.4.1. CUT SECTION OF SOLIDS


## AIM
To create the solid model from given drawing and section the solid model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3.16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1. Open a new file and then select sketch icon 2. Select the chosen plane for sketching 
3. Use the Line, Circle, Arc, Rectangle, Polygon, and other sketching tools available in Autodesk Fusion 360 to create the required 2D geometry. Draw each component carefully according to the shape and proportions shown in the given sketch.
   <img width="337" height="548" alt="Screenshot 2026-10-05 190607" src="https://github.com/user-attachments/assets/75c00158-452d-4b4d-98ae-e86bb265bd86" />

5. Use sketch modifying features such as Trim, Cut, Mirror, Move, Extend, Offset, and Fillet to edit, modify, and refine the sketch according to the given drawing.
<img width="247" height="372" alt="Screenshot 2026-10-05 190639" src="https://github.com/user-attachments/assets/a7e301bb-32f3-43af-8775-ba3a3dfb7d52" />

6. Use inspect feature to measure the dimensions of sketch.
